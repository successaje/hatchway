# Code of conduct

We want Hatchway to be a welcoming project for everyone, regardless of background, identity or
experience.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback about code, not people.
- Be patient with newcomers and with questions that seem basic.
- Respect people's time, privacy and boundaries.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, trolling, or sustained disruption.
- Publishing others' private information without permission.
- Soliciting private keys, seed phrases or funds, or posting scam links.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions) and when representing
the project elsewhere. Report concerns privately to the maintainer through the contact on the
maintainer's GitHub profile. Maintainers may edit or remove contributions and temporarily or
permanently ban participants who violate this code.

This code is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
